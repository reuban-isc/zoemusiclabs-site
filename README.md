# zoemusiclabs-site

Public support and privacy pages for ZoeMusicLabs apps, served by GitHub
Pages at https://zoemusiclabs.com/ (privacy policy for every app at
https://zoemusiclabs.com/privacy/).

The source of truth is `site/` in the private zoemusiclabs repository; copy
changes from there. Plain HTML and CSS only: no scripts, trackers, or files
from other sites.
